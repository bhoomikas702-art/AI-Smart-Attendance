# AI Smart Attendance System

An AI-powered attendance management system that uses face recognition to automatically identify registered students and record their attendance.

## Features

- AI-based face recognition
- Automatic attendance marking
- Student registration through webcam
- Student face image management
- Attendance records management
- Student database using CSV files
- Professional animated desktop interface
- Live attendance dashboard
- Attendance history
- Student information management
- Real-time camera-based recognition
- DeepFace and OpenCV integration

## Technologies Used

- Python
- OpenCV
- DeepFace
- Tkinter
- CSV
- NumPy
- Computer Vision
- Face Recognition
